Este Package contiene las features con los casos de prueba automatizados.

CONSIDERACIONES:

1- En el Package donde esta el Namespace debo crear uno con el nombre del componente de mi servicio. Este se puede ver dentro del mismo endpoint.

Ejemplo: https://gwqa.bice.cl/appper/bff-account/v1/account/debit/debit-balane

El nombre del componente en este caso es bffAccount (lower camel case).

2- Debo crear una Package indicando la version correspondiente. Esta debe contener lo siguiente:

		a. data (Package)
			i. json (Casos de Prueba): endPath200.json —> debitBalance200.json

		b. schemas (Package)
			i.  requests (Package): endPath_body.json —> debiBalance_body.json
			ii. responses (Package): endPath.json —> debitBalance.json

		c. azure.json (File): Debe contener lo siguiente:
            a. planId
            b. suiteId
            c. component
            d. funcionalidad

		d. feature (File): endPath.feature —> debit-balance.feature
			i. tags (Background):
				a. cluster: hbp
				b. nameSpace: appPersonas
				c. componente: bff-account
				d. componente_endPath: bff-account_debit-balance

			ii. tag (scenario outline)
				a. componente_endPoint: bff-account_debit-balance_200
